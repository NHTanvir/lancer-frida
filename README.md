# lancer-frida

Rust clone of `frida`. Part of the Lancer ecosystem — a complete 2026 AI-era bug bounty toolkit.

🚧 **In development.**

## Build

### Windows
Double-click `build.bat` or run from cmd:
```
build.bat
```
Output: `build\lancer-frida.exe`

For a packaged dist build:
```
build-windows.bat
```
Output: `dist\lancer-frida-windows-x86_64\bin\lancer-frida.exe`

### Linux / macOS
```bash
./build-linux.sh
```
Output: `build/lancer-frida`

### Requirements
- [Rust / Cargo](https://rustup.rs)
- (Windows) Visual C++ Build Tools 2019/2022
